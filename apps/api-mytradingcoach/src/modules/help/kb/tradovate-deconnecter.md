Dans [Mes comptes](/accounts), clique sur « Déconnecter » sur la ligne du compte. La synchro s'arrête.
Tes trades déjà importés restent, sauf si tu choisis de les supprimer. L'app t'affiche d'abord combien de trades viennent de ce compte Tradovate.
Les jetons de connexion sont effacés quand tu déconnectes.
