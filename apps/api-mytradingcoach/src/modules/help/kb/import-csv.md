Dans le [Journal](/journal), clique sur « CSV ».
- Source « Tradovate » : ajoute le fichier des trades (Performance, obligatoire) et, si possible, le Cash history pour avoir les frais exacts. Le plus simple reste quand même de connecter ton compte Tradovate.
- Source « Autre broker » : plusieurs formats d'export courants sont reconnus d'office, en gratuit. Si le format n'est pas reconnu, l'import IA lit ton fichier, mais il est réservé au Premium.
