Dans [Profil > Paramètres](/profil?tab=params), bloc « Discord », clique sur « Générer un code ». Tape ensuite /verify dans Discord et colle ce code. Ne le partage pas.
Ton rôle sur le serveur suit ton plan (membre ou Premium). Tu peux délier ton Discord au même endroit.
