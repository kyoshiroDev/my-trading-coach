Ta base de données est hébergée en France chez OVH, et tes données ne sont jamais vendues.
Pour l'IA, on utilise l'API de Claude (Anthropic). Selon la fonction, elle reçoit tes trades, tes notes et le nom de tes comptes, mais jamais ton nom ni ton e-mail, et elle n'a pas le droit d'entraîner ses modèles dessus.
Pour une copie de tes données en CSV ou pour exercer tes droits, écris à support@mytradingcoach.app. Tout est détaillé dans la [politique de confidentialité](https://www.mytradingcoach.app/politique-confidentialite).
