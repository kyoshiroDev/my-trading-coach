Un formateur partenaire peut te donner un code, souvent dans son lien. Le code baisse le prix du Premium selon ses conditions, affichées avant le paiement : à vie, ou pendant quelques mois puis prix normal.
Tu le saisis dans le champ « Code partenaire » de la fenêtre des offres.
Règles :
- un seul code par personne, réservé à qui n'a jamais été abonné ;
- pas de cumul avec l'offre fondateur ; face au parrainage, c'est la réduction la plus avantageuse qui s'applique ;
- les conditions obtenues ne changent plus, et la remise s'arrête si ton abonnement se termine.
