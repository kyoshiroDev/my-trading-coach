Les {{FOUNDER_SEATS}} premiers abonnés ont le Premium à {{FOUNDER_MONTHLY}} € par mois ou {{FOUNDER_YEARLY}} € par an TTC. Le prix est bloqué à vie tant que l'abonnement reste actif, nouveautés comprises. {{FOUNDER_SEATS_LABEL}}.
Il n'y a pas d'essai : le premier paiement est immédiat. Pendant ton Premium offert, tu peux réserver ta place sous conditions (voir les CGU).
Tu es satisfait ou remboursé pendant {{FOUNDER_REFUND_DAYS}} jours après le premier paiement. Si tu résilies, tu perds le tarif. L'offre ne se cumule ni avec un code partenaire ni avec le parrainage.
