Va dans [Mes comptes](/accounts) et clique sur « Connecter Tradovate » sur la ligne du compte. Pas encore de compte ? Ajoute-le avec « + Compte » dans le sélecteur de compte.
Tu es redirigé vers la page de connexion officielle Tradovate. Connecte-toi avec les identifiants de ta plateforme (NinjaTrader ou Tradovate) ou avec ceux de ta prop firm, puis autorise MyTradingCoach en lecture seule.
Une prop firm = une connexion : répète l'opération pour chaque firm. Ensuite, les trades du compte se synchronisent tout seuls.
