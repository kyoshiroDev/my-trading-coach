Va dans [Profil > Paramètres](/profil?tab=params), bloc « Abonnement », et clique sur le bouton pour passer Premium.
Tu choisis ton offre (mensuel, annuel, fondateur s'il reste des places, ou code partenaire), puis tu paies sur la page de paiement sécurisée par Stripe.
Le cadenas d'une fonction Premium ouvre la même fenêtre.
