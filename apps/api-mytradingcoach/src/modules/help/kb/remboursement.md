Avec l'offre fondateur, tu es satisfait ou remboursé pendant {{FOUNDER_REFUND_DAYS}} jours après le premier paiement réellement prélevé. Demande-le avec le lien « Satisfait ou remboursé : demander le remboursement » dans Profil > Paramètres > Abonnement. Tu es remboursé en entier, l'abonnement est annulé et tu perds le tarif fondateur.
Pour les autres abonnements, les [CGU](https://www.mytradingcoach.app/cgu) prévoient le droit de rétractation. Pour toute demande, écris à support@mytradingcoach.app.
