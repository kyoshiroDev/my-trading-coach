La [démo](/demo) te fait explorer MyTradingCoach avec des données d'exemple, sans créer de compte.
Elle est en lecture seule : tu peux tout regarder, mais rien ajouter ni modifier (« Action non disponible en mode démo »).
Pour l'utiliser avec tes propres trades, [crée ton compte](/register) : c'est gratuit.
