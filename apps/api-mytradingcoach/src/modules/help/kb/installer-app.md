Ouvre [la page d'installation](/installer) sur ton téléphone : elle t'affiche les étapes pour ton appareil.
Pas de store, rien à télécharger : c'est ton navigateur qui ajoute MyTradingCoach à ton écran d'accueil. Sur iPhone, passe par Safari.
Sur ordinateur, la même page te propose « Installer sur cet ordinateur ».
