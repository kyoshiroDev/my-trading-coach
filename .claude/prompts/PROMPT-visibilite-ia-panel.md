Si le mode n'existe pas pour un service ou si tu n'es pas sûr que la mémoire est coupée, note « mémoire possible » sur ce service.

## Ce que tu relèves pour chaque réponse

- Concurrents cités (noms).
- Sources citées (domaines ou URL, tels qu'affichés). Pour Perplexity et les services qui affichent des sources, note-les toutes.
- Exactitude de ce qui est dit sur MTC, uniquement pour D et E, selon les faits suivants : lecture seule, aucun ordre passé, aucun conseil d'achat ou de vente, compatible Tradovate avec import automatique et saisie manuelle ; NinjaTrader : ne conclus pas, note seulement ce que dit la réponse. Prix : note seulement ce qui est dit, ne le juge pas (je comparerai moi-même). Marque « à vérifier » plutôt que « faux » quand tu n'es pas sûr.
- Remarques : réponse refusée, hors sujet, service bloqué, mémoire possible, version du modèle affichée si visible, date et heure.
- Une seule exécution par question : dis dans le rapport que c'est un échantillon (les réponses des IA varient d'une fois à l'autre).
